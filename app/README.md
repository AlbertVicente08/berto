# app/

Popup y avatar de Berto, hecho con **Tauri 2 + React + TypeScript**. Se crea en la Fase 0 y se desarrolla en la Fase 1.

## Desarrollo

- Interfaz web: React 19 + TypeScript + Vite.
- Backend de escritorio: Tauri 2 (Rust).
- En desarrollo: `npm run tauri dev`
- En producción: `npm run tauri build`
